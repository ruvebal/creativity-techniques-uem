# PHASE T1 — Tension cards · form assignment

**Depends on:** T0 `DONE`

## Form law

| Form | Use when | Voice |
| ---- | -------- | ----- |
| **Haiku** | Observation that should stay concrete / seasonal | 3 lines; no punchline sermon |
| **Koan** | Paradox the student must sit with | Master/student; end in silence or unanswered cut |
| **Máxima** | Compressible law (Lao Tzu) | Short; one cut |
| **Yoda** | Same as máxima; inversion adds force | Permitted subclass of máxima — still labelled `Yoda` or `Máxima` in the include |

Assign **one primary form** per tension; optional secondary form for the same chapter.

## Do

1. For each `status: open` tension, set `form_hint` and `chapter`.  
2. Mark `status: assigned`.  
3. Report: table of id → form → chapter.

## Fail closed

- Assigning haiku to an abstract policy rant without a concrete image → rewrite hint or change form.
