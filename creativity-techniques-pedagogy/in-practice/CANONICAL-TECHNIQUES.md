## Techniques

### Alternative Uses Task (AUT)

`alternative-uses-task` · generation · divergent · units U1, U2

- **Source:** chen-2011 — p. 26 (unusual-uses / brick test reported with Guilford's abilities) (verified)
- **Time:** 15 min · **Group:** individual, class pooling · **Materials:** object or image, paper, timer
- **Evidence:** Chen 2011, 26 cautions that AUT scores may say little about talent in a specific domain; use as practice, not a talent measure.
- **Accessibility:** Oral or typed lists accepted; image prompt can replace a physical object.
- **Catalogue records:** 0 (none: finding for the IP cascade)

Steps (classroom adaptation):

1. Show one everyday object (brick, paperclip, shoe) and start a visible timer.
2. Each student lists as many different uses as they can, alone and in silence.
3. Stop; each student counts ideas (fluency) and use categories (flexibility).
4. Pool the class lists; a use that appears on only one list counts as original.
5. Each student picks one use and adds detail to it (elaboration).
6. Discuss which category shifts produced the less obvious uses.

### Brainstorming (Osborn ground rules)

`brainstorming-osborn` · generation · divergent · units U2, U4

- **Source:** osborn-1942 — chap. 4 (ground rules for a think-up conference: judicial judgment ruled out until all ideas are in) (verified)
- **Time:** 20 min · **Group:** 4–8 · **Materials:** board or flipchart, markers, timer
- **Evidence:** Amabile 1979, 221: expecting evaluation lowered the judged creativity of artworks, which supports a judgement-free round; group productivity: gap: Diehl and Stroebe 1987.
- **Accessibility:** Allow written contributions on cards for students who do not want to speak aloud.
- **Catalogue records:** 59 — labels: Brainstorming Session Setup ×13; Evaluation Session ×10; Classroom Brainstorming Exercise ×8; Brainstorming Bulletin Board ×7; Brainstorming with Cards ×5 · methods: rule 59

Steps (classroom adaptation):

1. State one problem as a question everyone can read.
2. Agree the ground rule: no criticism until the idea round ends.
3. A scribe records every idea, numbered, in the speakers' words.
4. Invite combinations and improvements of ideas already on the board.
5. Stop at the time limit, not when ideas slow down.
6. Only then move to a separate selection technique.

### 6-3-5 brainwriting

`brainwriting-635` · generation · divergent · units U2, U4

- **Source:** gap — gap work: Rohrbach 1969 (attribution unverified; manifest key rohrbach-1969) (held)
- **Library note:** Michalko 2010 (Thinkertoys), not in references.yml, describes Geschka's card brainwriting (Battelle), a silent written method of the same family but not 6-3-5; no library record describes 6-3-5 itself (A11/F2).
- **Time:** 20 min · **Group:** 6 (3–6 works) · **Materials:** one 3-column grid sheet per person, pens, timer
- **Evidence:** gap: Rohrbach 1969; gap: Diehl and Stroebe 1987 (production blocking in talking groups).
- **Accessibility:** Typed shared document can replace paper; allow extra time per round where needed.
- **Catalogue records:** 5 — labels: Brainwriting ×5 · methods: rule 5

Steps (classroom adaptation):

1. Groups of six sit in a circle; each has a sheet with a three-column grid.
2. Each person writes three ideas in the first row (one per column).
3. Pass the sheet to the left; read what is there and write three new or built-on ideas.
4. Repeat for each round; nobody talks during the rounds.
5. After the last round, each person stars the two ideas they would develop.
6. Classroom note: six rounds need about 30 minutes; three rounds fit a Lab (say so on the card).

### Nominal group (solo ideas, then pool)

`nominal-group` · generation · both · units U2, U4

- **Source:** gap — gap work: Diehl and Stroebe 1987 (manifest key diehl-1987) (gap)
- **Time:** 15 min · **Group:** 3–6 working alone, then pooled · **Materials:** paper or sticky notes, timer
- **Evidence:** gap: Diehl and Stroebe 1987; gap: Mullen, Johnson and Salas 1991.
- **Accessibility:** Fully silent format; suitable for students who prefer not to speak.
- **Catalogue records:** 0 (none: finding for the IP cascade)

Steps (classroom adaptation):

1. Give the same brief and time limit used by a comparison group.
2. Each student generates ideas alone, in silence.
3. Pool all lists and remove exact duplicates.
4. Count unique ideas and compare with the interacting group's count.
5. Discuss what talking added or blocked.

### SCAMPER

`scamper` · generation · divergent · units U2, U3

- **Source:** gap — gap work: Eberle 1971 (attribution unverified; manifest key eberle-1971) (held)
- **Library note:** SCAMPER records from Michalko 2010 (Thinkertoys), not in references.yml.
- **Time:** 25 min · **Group:** 1–4 · **Materials:** prompt card, object or image, paper
- **Evidence:** gap: Eberle 1971.
- **Accessibility:** Prompt card in large print; image or description can replace a physical object.
- **Catalogue records:** 127 — labels: SCAMPER Technique ×32; SCAMPER Combine ×15; Modify Idea ×14; Magnify Idea ×12; Put to Other Uses ×11 · methods: rule 123, model 4

Steps (classroom adaptation):

1. Pick one existing product, service or artefact.
2. Work through the prompt letters one at a time - substitute, combine, adapt, modify, put to another use, eliminate, rearrange or reverse.
3. Write at least one change for every prompt, even a weak one.
4. Mark the three changes that most alter how the thing is used.
5. Sketch one of them.

### Phoenix checklist (problem questions)

`phoenix-checklist` · framing · both · units U3, U4

- **Source:** gap — gap work: origin unverified (held)
- **Library note:** Records from Michalko 2010 (Thinkertoys), not in references.yml.
- **Time:** 20 min · **Group:** 1–3 · **Materials:** question sheet, paper
- **Evidence:** untested
- **Accessibility:** Questions can be read aloud and answered orally.
- **Catalogue records:** 26 — labels: Phoenix Checklist ×25; Checklist of Problem-Solving Questions ×1 · methods: rule 25, model 1

Steps (classroom adaptation):

1. Write the problem in one sentence.
2. Answer a set of questions about the problem (what is unknown, what is given, what is similar) in writing.
3. Then answer questions about the plan (which parts can be solved first, what would a partial solution look like).
4. Rewrite the problem statement using what the questions revealed.
5. Compare the first and last statements.

### Morphological box (idea box)

`morphological-box` · generation · divergent · units U2, U3, U5

- **Source:** gap — gap work: Zwicky 1969 (attribution unverified; manifest key zwicky-1969) (held)
- **Library note:** Idea Box records from Michalko 2010 (Thinkertoys), not in references.yml.
- **Time:** 25 min · **Group:** 1–4 · **Materials:** grid sheet or spreadsheet, dice (optional)
- **Evidence:** gap: Zwicky 1969.
- **Accessibility:** Spreadsheet version for screen readers; dice can be replaced by a random-number app.
- **Catalogue records:** 39 — labels: Idea Box ×37; Morphological Analysis ×1; Matrix Technique ×1 · methods: rule 39

Steps (classroom adaptation):

1. List four to six parameters of the problem as column headings.
2. Under each, list several options.
3. Pick one option per column at random or by choice to form a combination.
4. Repeat for at least five combinations, including one that looks absurd.
5. Develop the most promising combination into a short description or sketch.
