# Methods — Creativity Techniques

**Data-as-code** (repo root). Edit `*.yml` → `npm run hydrate` → **one** public route `/methods/en/` (`#` section hashes).

**Student-facing:** only entries with `kind: practice-learning` (projects, problems, workshops, critique, prototyping, process portfolio).

**Research packs** (funded/scholarly, e.g. `musae-dfa.yml` + `musae-dfa/PROFILE.md`) stay for pedagogy/research; they are **not** hydrated into the student Methods index.

See [`SCHEMA.md`](./SCHEMA.md).
