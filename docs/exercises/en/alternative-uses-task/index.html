Alternative Uses Task

List many uses for one ordinary object under a timer. Fluency first; then notice flexibility across categories.

  • ~15 min
  • individual, then shared board
  • technique alternative-uses-task
  • unit U1
  • unit U2

Source book Chen, Chaomei. 2011. Turning Points: The Nature of Creativity. Beijing: Higher Education Press; Berlin: Springer.

On this page

Requirements

Time ~15 minutes
Group individual, then shared board
Access Oral or typed lists accepted; image prompt can replace a physical object.

Materials

  • object or image
  • paper
  • timer

Before you start

  • One shared prompt object for the class.
  • No judging during the timed list.

Steps

Follow in order — your professor may shorten the clock.

  1. Show one everyday object (brick, paperclip, shoe) and start a visible timer.
  2. Each student lists as many uses as possible in silence.
  3. Stop; count the list (fluency).
  4. Mark how many different categories appear (flexibility).
  5. Share two surprising uses with a neighbour; keep the full list for the portfolio.

Source

How many uses can you think of for a brick? […] More interestingly, individuals differ considerably in terms of the number of answers they can come up with. Some can think of many different ways to use a brick, whereas others may be only able to think of one or two. Based on the ability of an individual to answer these types of questions, Hudson differentiated individuals in terms of two intellectual types: convergers, who would specialize in mathematics and physical sciences, and divergers, who are likely to excel in the arts and make surprising cognitive leaps.

— (Chen 2011, 40)

Classroom note. Classroom timing and portfolio fields are course adaptations of the unusual-uses / brick prompt reported with Guilford’s abilities.

Portfolio

Timed list; fluency count; flexibility note; two shared uses.

Judged by: Portfolio rubric — creative fluency, flexibility, and originality
