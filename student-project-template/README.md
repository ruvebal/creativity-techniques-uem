# Student project template — Técnicas de Creatividad

Scaffold for student repositories (creativity exercises and portfolio pieces).

Suggested spine:

```
research/     brief, references, consent notes
ideation/     sketches, technique logs, selection rationale
development/  iterations, prototypes, written reflections
presentation/ oral delivery assets, final deliverables
evaluation/   process narrative, AI-use declaration
```

Fill this template as the first units land. Until then, keep exports local and consent-ready.
